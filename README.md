# Platform Lab

A local Platform Engineering Lab running on Windows + WSL2 using open-source tools:
K3s, ArgoCD, GitOps, Terraform, Ansible, Observability stack, and local AI (Ollama + Bielik).

This repository is a technical portfolio demonstrating skills in:
- Kubernetes
- GitOps & CI/CD
- Infrastructure as Code
- Platform Engineering
- Observability & Monitoring
- Local AI model deployment
